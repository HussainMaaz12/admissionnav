# Delhi NCR Engineering Admission Navigator

Strategic guides and analytical tools for BTech CSE college admissions in Delhi NCR, featuring premium royal styling, interactive data analysis, and comprehensive institutional comparisons.

## 📋 Pages

1. **Interactive Master Navigator** (`delhi_ncr_engineering_admission_navigator.html`)
   - Interactive college comparison matrix
   - Advanced filtering and sorting
   - Cost vs. Package analytics
   - Deep institutional profiles
   - Strategic tier categorization

2. **CSE Colleges Report** (`delhi_ncr_cse_colleges_report.html`)
   - Comprehensive ranking dashboard
   - Placement statistics
   - ROI analysis
   - College comparison tables
   - Strategic admission guidance

## 🎨 Features

- **Premium Royal Aesthetic**: Navy (#1a1f4d) and gold (#d4af37) color scheme
- **Smooth Animations**: Entrance effects, hover interactions, gradient transitions
- **Fully Responsive**: Mobile, tablet, and desktop optimized
- **Data-Driven**: 20 institutions with comprehensive metrics
- **Interactive Visualizations**: Chart.js powered analytics
- **Glass-Morphism Effects**: Modern UI with backdrop blur

## 📦 Deployment on Vercel

### Option 1: Automatic Deployment (Recommended)

1. Go to [Vercel Dashboard](https://vercel.com/dashboard)
2. Click **"Add New..."** → **"Project"**
3. Select **"Import Git Repository"**
4. Paste: `https://github.com/HussainMaaz12/admissionnav`
5. Click **"Import"**
6. Click **"Deploy"**

Your site will be live at: `https://admissionnav.vercel.app/`

### Option 2: Using Vercel CLI

```bash
npm install -g vercel
cd admissionnav
vercel
```

### Option 3: GitHub Integration

1. Connect your GitHub account to Vercel
2. Import the repository from your Vercel dashboard
3. Automatic deployments on every push to main
